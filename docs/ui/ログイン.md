# ログイン画面（UI仕様）

Screen ID: AUTH_LOGIN

**関連ドキュメント**: [Flow](../flow/ログイン.md) | [Validation](../validation/ログイン.md) | [DB](../db/ログイン.md)

## Scope（対象範囲）

- 登録
- ログイン
- ログイン中の表示名とログアウト

## 対象画面

- **登録**: `/register/`
- **ログイン**: `/login/`
- **表示名**: ログイン中の全画面の上部

## 使用API

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/session`

## 画面コンポーネント

- `RegisterPagePresentation`
- `LoginPagePresentation`
- `AccountBar`

## 画面の構成

### 登録

- メールアドレス
- パスワード
- 表示名
- 登録

### ログイン

- メールアドレス
- パスワード
- ログイン
- 失敗時は原因を分けない文言

### 上部

- loading
- 未ログイン: ログインと登録へのリンク。表示名は出さない
- ログイン中: 表示名とログアウト

## UIイベント

### 登録成功

- **送信後**: `/tasks/` へ進む

### ログイン成功

- **送信後**: `/tasks/` へ進む

### ログアウト

- **クリック時**: 表示名を消す

## エラー表示（UI）

- request failure は alert
