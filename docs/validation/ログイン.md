# ログイン（バリデーション・エラーハンドリング）

Validation ID: AUTH_LOGIN

**関連ドキュメント**: [Flow](../flow/ログイン.md) | [UI](../ui/ログイン.md) | [DB](../db/ログイン.md)

## Scope（対象範囲）

- POST /api/auth/register
- POST /api/auth/login
- GET /api/auth/session
- POST /api/auth/logout

## 対象API

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/session`

## Validation カテゴリ

### 必須チェック (required)

- register: `email`, `password`, `display_name`
- login: `email`, `password`

### 文字数チェック (length)

- `password`: 登録時 8〜200
- `display_name`: trim 後 1〜80
- `email`: trim し小文字化したあと最大 255。形式はメールアドレス

## サーバーサイドバリデーション

Laravel FormRequest で実施。同じメールアドレスは 422。大文字小文字は同一。

## エラーハンドリング（HTTP）

### 422

- 入力不正
- 同じメールアドレス。message は `Email is already registered`

### 401

- ログイン失敗。message は常に `Invalid credentials`
- session が未ログイン

### 500

- unexpected internal error
