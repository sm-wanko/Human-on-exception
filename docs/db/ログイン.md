# ログイン（DB・テーブル・SQL）

DB ID: AUTH_LOGIN

**関連ドキュメント**: [Flow](../flow/ログイン.md) | [UI](../ui/ログイン.md) | [Validation](../validation/ログイン.md)

## Scope（対象範囲）

- users table insert / read

## 使用テーブル

- `users`

## DB Write Order

1. register: users INSERT

各 request は単一 table write。ログインとログアウトは行を更新しない。

## テーブル登録項目

### users

| カラム | 値 | 備考 |
|--------|-----|------|
| id | auto | PK |
| email | string | unique。保存前に小文字化 |
| password | string | ハッシュ。平文は保存しない |
| display_name | string(80) | 表示名。email とは別 |
| created_at | timestamp | Laravel |
| updated_at | timestamp | Laravel |

## Query

- ログイン: email 完全一致で 1 件

## DB 非関与エンドポイント（N/A）

| method | path | 振る舞い | 実装ファイル |
|---|---|---|---|
| POST | `/api/auth/logout` | DB write なし | `apps/backend/app/Http/Controllers/AuthController.php` |
| GET | `/api/auth/session` | DB write なし。読み取りのみ | `apps/backend/app/Http/Controllers/AuthController.php` |

## 監査

アカウント作成は Task の会員監査対象ではない。`created_by` は付けない。
