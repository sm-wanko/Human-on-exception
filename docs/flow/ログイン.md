# ログインフロー

---

Flow ID: AUTH_LOGIN

**関連ドキュメント**: [UI（画面仕様）](../ui/ログイン.md) | [Validation（バリデーション）](../validation/ログイン.md) | [DB（テーブル・SQL）](../db/ログイン.md)

## Scope（対象範囲）

- メールアドレス、パスワード、表示名による本人登録
- ログイン、ログアウト、ログイン中の表示名
- パスワード再設定メール、メール到達確認、OAuth は対象外

## Actor

- **User**: 自分のアカウントを作ってログインする人
- **Client**: TypeScript Frontend
- **Server**: Laravel Controller / Service / Repository

## Entry Point

- **API**: `POST /api/auth/register`, `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/session`
- **画面**: 登録 / ログイン。表示名はログイン中の全画面

## Normal Flow

### 登録

1. **User** メールアドレス、パスワード、表示名を送る
2. **Server** アカウントを1件作り、ログイン状態にする
3. **Client** 表示名を出す

### ログイン

1. **User** メールアドレスとパスワードを送る
2. **Server** 一致すればログイン状態にする
3. **Client** 表示名を出す

### ログアウト

1. **User** ログアウトする
2. **Server** ログイン状態を消す
3. **Client** 表示名を出さない

## DB Write

- register: users insert

## Response

- register: 201 `{ display_name }`
- login: 200 `{ display_name }`
- logout: 204
- session: 200 `{ display_name }`

## Error Flow

- 422: 入力不正、または同じメールアドレス
- 401: ログイン失敗。未知のメールと誤パスワードは同じ本文
- session 未ログイン: 401

## ログ出力

- framework error log。成功ログなし。
